# Safari SD5008 可迁移项目记忆包

整理日期：2026-09-21

本包保存讨论过程、用户偏好、决策结果、当前研究计划及未决事项。它不是只含proposal的资料包，也不是旧对话逐字导出。

## 在全新项目中加载

最简单：上传包外提供的 `Safari_SD5008_完整项目记忆.md`，以及需要时上传两份proposal。

若新项目支持压缩包：上传或解压本包，先读本README，再读PROJECT_MEMORY、DECISION_LOG和LITERATURE_MEMORY，最后读proposals中的中英文方案。

可复制下面这段话作为新项目的第一条消息：

> 请先读取我上传的《Safari SD5008 完整项目记忆》，将其作为本项目的历史上下文。若上传的是文件夹，请先读README.md、PROJECT_MEMORY.md、DECISION_LOG.md、LITERATURE_MEMORY.md，再读proposals中的中英文V3方案。请区分我明确确认的决定、助手提出的建议及仍未决定的事项；以后续用户指示为最高优先级。不要把proposal计划、研究假设或研究者推测写成已完成的实地结果。先简短概括你的理解和最需要确认的当前进展，然后按我的下一条任务继续。若环境支持持久记忆，请保存此项目上下文；若不支持，只需在本项目中作为参考，不要声称已经自动写入系统记忆。

## 文件清单

- PROJECT_MEMORY.md：核心综合记忆，涵盖动机、方向、用户要求、方法、工作量、课程与未决项。
- DECISION_LOG.md：讨论演变、各版变化、已被替代的建议。
- LITERATURE_MEMORY.md：10篇当前文献的作用、核查边界、DOI，以及旧版移除文献的原因。
- proposals/Safari_SD5008_Research_Proposal_V3_中文.md：当前中文方案。
- proposals/Safari_SD5008_Research_Proposal_V3_English.md：当前英文方案。
- SHA256SUMS.txt：文件完整性校验值。

## 使用边界

所有链接均使用相对文件路径或公开DOI，不依赖旧项目电脑目录。包内不含原课程PDF、论文PDF、Google Drive文件或完整聊天日志；需要逐页核验时应另行提供原始材料。

迁移文件不会自动给新项目授予旧项目的连接权限，也不保证任何产品自动导入持久记忆。新助手必须实际读取上传文件。

当前课表是2026年版本的历史核查结果。加载时请结合当前日期核实进展，而不是默认9—12月任务尚未发生。
