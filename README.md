# Research and Analysis for Design

**SD5008 · PolyU ISD · Safari**  
面向初到香港人群的注意力分配与导航信息设计  
**Attention Allocation and Navigation Information Design for Newcomers to Hong Kong**

这是 Safari 小组的研究、讨论过程、文献与成果档案。我们研究陌生步行导航中的信息如何帮助定向、行动和确认，以及在什么情境下伴随交互负担。预期产出是情境化信息分类与初步设计建议。

**仓库版本：v0.2.0 · 整理日期：2026-10-27 · 时区：Asia/Hong_Kong**

## 当前基线

用户于 **2026-10-26** 提供了正式路线及四份 v3 执行文件。正式路线为 **PolyU 南门 → K11 Art Mall（必要途经）→ K11 MUSEA 的 Barbour 店门口（3F 319）**。Art Mall 是途中节点，到 Barbour 店门口才结束。见[路线档案](docs/fieldwork/ROUTE.md)。

最新版手册采用一位研究员跟随一位参与者、现场笔记为主、挂脖 GoPro 辅助核对及片段回顾，并统一用香港时钟记录。七个简写代码与旧版标签有对应关系，见[代码对照](docs/fieldwork/CODEBOOK_CROSSWALK.md)。

**2026-10-27 已开始实地观察**：P01、P02 的原始资料在 Google Drive／iCloud，P01 有一份[初步观察分析](docs/fieldwork/sessions/P01_2026-10-27_UserA_observation-analysis.md)（未校对，不是结论）。已填写的 v3 记录表、完整访谈和伦理批准文件仍未取得。地图的约 28 分钟／1.9 km 是手册中的规划估算，室内找店时间另核对。

9 月中英文 proposal V3 与 10 月汇报均按原件保存。发生冲突时，先看[版本适用关系](docs/PROJECT_STATE.md)；不要用旧的双人分工、候选终点或 45–60 分钟预算覆盖新手册。
