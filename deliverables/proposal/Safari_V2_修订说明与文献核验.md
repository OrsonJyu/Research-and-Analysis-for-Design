# Safari 第二版修订说明与文献核验

2026年9月19日。与英文 V2 配套，供小组讨论，不是新增课程要求。

## 已采用的小组选择

- 四人，每人每周约3小时；按9月21日至12月6日11周，合计132人时，不含课堂和个人笔试复习。
- 步行观察与事后半结构式访谈合并为一次45–60分钟的活动。
- 6名正式参与者为核心；最多补充2人，条件是仍有明确证据缺口、时间允许且在伦理批准范围内。另1名预研究参与者，不计入正式样本。
- 不安排必做的第二轮测试。每人的事后访谈中用约5分钟的信息卡片活动帮助表达需求；它不是完整共创工作坊，也不证明分类有效。

## 对第一版的修订

1. 用2026年原始课程安排替换泛化的六周计划。汇报为9月24日、10月8日、10月29日、11月12日、11月26日；12月3日个人笔试，12月6日报告截止。
2. 更新正式课程要求：报告约5000–8000英文词，APA第7版，PDF小于10MB，附查重报告。正式course brief的评分是课堂及互评25%、个人笔试20%、汇报25%、研究报告30%，替代早期TBC文件。
3. ISD导师补为Dr. Rui He。说明书中的学生联系人、指定存储位置及保存期限仍需在招募前与导师确定。
4. 文献由5篇增至10篇，新增3篇直接相关导航研究和2篇方法文献；每篇均在正文有作用。书目年份按最终卷期：Bartling和Nagata均列2026年，其首次在线发表时间为2025年，不是书目错误。
5. 从8–12名参与者加4–6次回访，精简为6名核心参与者、最多2名补充参与者，无必做回访。
6. 删除自设1–7分负荷评分，采用具体片段解释和行为记录。行为计数不自动把研究变成mixed methods；没有直接测量认知负荷、注意力资源或疲劳。
7. 新增问题—数据—方法对应表、框架分析流程，以及从证据到设计建议的追溯步骤。
8. 附GenAI使用说明和本次及首版主要提示词，不代替小组审阅，也不虚构已经完成审阅。课程要求记录具体工具和提示词，应保留完整对话记录及后续修改记录。

## 方法为什么这样选择

| 方法 | 在本研究中的作用 | 判断与边界 |
|---|---|---|
| 低干预步行观察 | 记录查看、停顿、重新定向和环境条件的先后关系 | 核心。对应W03第9–11页；任务由研究者指定且研究者在场，不称为完全自然、无干预或隐蔽观察。 |
| 事后半结构式访谈 | 理解用户当时想确认什么、为何采取行动 | 核心。对应W03第19页；用刚才的时间线支持回忆，开放提问后再追问，避免先问“是不是很累”。 |
| 信息卡片辅助表达 | 将本次旅程的4–6条信息放回需要它们的时刻，补充遗漏信息 | 嵌入访谈5分钟。借鉴W03第27页的实体工具思路，不直接把卡片偏好当作有效性或最终分类。 |
| Framework Method框架分析 | 用矩阵比较不同参与者，保留情境和原始证据链接 | 适合分类目标；借鉴Gale等（2013），需团队学习和导师反馈。它是分析方法，不是另一次数据收集。 |
| Focus group | 适合讨论共享规范和方案分歧 | 本轮不采用：个人导航片段比群体共识更重要，且增加招募协调和分析成本。W03第24–26页也讨论其局限。 |
| 问卷或A/B实验 | 可用于已明确构念或具体方案的后续检验 | 本轮不采用：目前先厘清需要和负担；6–8人观察不足以支持总体比例或可靠的效果检验。课件中的一般样本数提示不能当作跨研究通用的门槛。 |
| 完整共创工作坊或RtD | 若问题依赖制作新交互，可作为后续方向 | 本轮不列为必做。W02介绍RtD，不意味着每组都必须做产品；本研究当前证据主要来自情境观察与访谈。 |

这里的“适合”是针对本课题的判断，不是把slides中的所有方法当作必须完成的任务。尤其不能把采访解释视为心理机制的客观证明。

## 132人时工作预算

人时按所有成员投入相加计算，两位研究者同时工作1小时计2人时。

| 工作 | 小组合计人时 |
|---|---:|
| 文献与来源核查 | 16 |
| 方案、招募、路线和预研究 | 14 |
| 正式实地活动、就近交通和即时笔记 | 22 |
| 转写检查和编码 | 22 |
| 分类、反例与设计框架综合 | 12 |
| 五次汇报准备 | 14 |
| 最终报告整合与修订 | 20 |
| 缓冲 | 12 |
| 合计 | 132 |

这是预算，不是已经发生的工时。每周核对12人时上限，把早期整理直接用于后续汇报和报告，避免重复写作。最后两名参与者不自动招满；如转写或招募耗时超预期，优先保留6个完整案例并缩小结论范围。若6例数据仍薄弱，也不能声称已充分验证框架。

建议两对组员各负责3名核心参与者，轮换观察与访谈角色，交叉核查对方一例数据；不把“调研”和“分析”完全分给互不接触的成员。

## Sample借鉴与不沿用之处

- Sample 01：借鉴“子问题—所需数据—理由—方法”矩阵。它列出许多候选问题、方法与待读文献；本版将范围收窄，参考文献只收录实际引用的来源。
- Sample 02：借鉴把体验与实际行为联系起来的思路。不沿用问卷、观察、乘客访谈、运营者访谈全部并列的广泛任务量。
- Sample 03：借鉴清楚写对象、收集内容和单次时长。不沿用200人问卷样本，亦不因其使用“experiment”一词而把普通调查称为实验。
- 三份sample的日期不作为2026年排期依据；例文不是方法质量或事实准确性的保证。
