## 一、研究背景

本研究源于小组对初到陌生地区时出行体验的观察：一次原本为了游玩、探索城市或完成生活事务的出行，可能逐渐被“如何到达那里”占据。使用者需要看懂路线、把地图与眼前街道对应起来、寻找出口或入口，并不断确认自己是否走对。即使导航始终可用，完成这些判断仍可能消耗大量心力，让人没有余力欣赏周围环境。

我们关注的是，部分初到香港的人是否会在这一过程中产生 overwhelmed——一种面对当下信息与行动要求，感到应付不过来的体验。它可能表现为到了目的地却已无心游玩、不想继续探索下一个地点，或最终放弃原定目的地。这些是小组的研究出发点和希望追问的可能后果，尚不是对香港初来者的既定结论。

这一出发点得到相关质性研究的部分支持。Schmitt 等人（2019）发现，陌生公共交通出行常伴随持续警觉、主动搜集信息与不确定感；相较于熟悉旅程中的放松机会，使用者需要持续关注路线，而且即使提前准备也可能发生寻路错误。该研究关注公共交通，不能直接等同于步行，但提示我们：到达目的地本身可能成为一项需要持续投入的活动。[Schmitt et al., 2019](https://doi.org/10.1007/s11116-018-9880-9)

本研究将 overwhelmed 作为参与者的体验性描述，而非临床诊断，也不将其直接等同于客观测得的认知超负荷。以下几个视角用于解释它为何可能发生，并指导后续调查。

### 1. 陌生环境让原本顺手的移动变成一连串判断

缺少熟悉的空间参照时，人需要不断确定“我在哪里”“屏幕上的提示对应眼前哪条路”以及“下一步是否正确”。地图提供了方向，并不意味着使用者已经知道如何在实际环境中采取行动。

对陌生城市访客的步行研究发现，使用数字导航并未比使用纸质地图或当地标识消除更多焦虑；跟随推荐路线也不保证使用者充分了解周围空间。由此可见，信息可获得与有信心采取行动，是两个需要分别考虑的问题。[Vaez et al., 2020](https://doi.org/10.1080/14616688.2019.1696883)

### 2. 导航与体验城市争夺注意力

行走时，人可能需要同时阅读屏幕、留意行人与车辆、辨认地标，并记住下一步指示。多重资源理论说明，同时进行的任务在依赖重叠处理资源时可能相互干扰；移动交互研究则描述了城市情境中的注意力碎片化。情境性能力受限的视角进一步提示，环境和身体条件也会改变技术的使用难度。[Wickens, 2008](https://doi.org/10.1518/001872008X288394)；[Oulasvirta et al., 2005](https://doi.org/10.1145/1054972.1055101)；[Wobbrock, 2019](https://doi.org/10.1007/978-1-4471-7440-0_5)

据此，我们推测，即使每一条指示本身都能理解，在屏幕与环境之间反复转换注意力，仍可能使导航变得费力，并压缩欣赏城市的注意空间。这是需要通过研究检视的理论解释，而不是认定每次注意力转换都有害。

### 3. 问题可能是信息不合时宜，而不只是信息太多

地图内容过密、提示出现得太晚，以及缺少确认信息，可能带来不同困难：使用者有时不知道该关注哪一项，有时知道指示却无法对应环境，也可能因为无法确认而不断查看。

虚拟导航研究表明，地标显示条件与认知要求存在联系，而减少无关地图信息的帮助并非在所有情境下都成立。因此，overwhelmed 可能来自信息、时机与任务之间的不匹配，不能简单归结为“显示内容太多”。[Cheng et al., 2023](https://doi.org/10.3389/fnins.2023.1024583)；[Bartling et al., 2026](https://doi.org/10.1080/15230406.2025.2512075)

真实环境研究还发现，查看手机与停顿、路线错误相关，但因果方向尚不明确。因此，反复查看既可能是困难的表现，也可能是使用者主动恢复确定感的办法。[Shimokihara et al., 2025](https://doi.org/10.21037/mhealth-25-33)

### 4. 不确定性可能影响出行体验与继续探索的意愿

寻路不仅有到达与否的实际结果，也包含情绪体验。陌生目的地中的游客研究发现，感知到的寻路困难与焦虑相关。公园中的质性研究则显示，使用者会借助距离和方向信息，判断自己是否有信心走得更远。[Chang, 2013](https://doi.org/10.1080/14616688.2012.726270)；[Hardwicke et al., 2024](https://doi.org/10.1080/23748834.2024.2313307)

这些发现使愉悦感、信心和继续探索的意愿成为值得研究的结果，而不只关注是否到达。不过，现有证据尚不能直接证明香港初来者普遍经历“导航消耗精力，继而放弃探索”的完整因果过程。本研究将通过参与者叙述追问这种联系，同时保留陌生环境令人兴奋、额外信息带来安心等不同体验。

因此，本研究希望了解初到香港的人在陌生步行导航中何时感到应付不过来，这些时刻如何与其整次出行体验关联，以及什么信息支持有帮助。最终形成连接信息作用、呈现条件、主观体验和行动的信息分类，并提出关于何时、如何传达导航信息的初步设计框架。

## 二、研究目标

1. 识别陌生步行旅程中的信息需求与可观察的交互片段。
2. 识别参与者报告的 overwhelmed 时刻，理解可能的困难来源，并追问其与愉悦感、信心、继续探索及抵达目的地之间的关系。
3. 建立连接信息作用、情境要求与参与者解释的分类，包含不同或相反的案例。
4. 提出有证据支持的信息呈现时机、详细程度及传达方式建议，并明确尚未验证的内容。

## 三、研究问题

核心问题：如何根据导航信息所关联的交互负担对其进行分类，并据此形成交互设计方法，改善信息呈现与传达的时机和方式？

负担被理解为与情境有关的体验，而非某一信息类别固定不变的属性。

- RQ1：初到香港的人在步行导航的不同阶段需要哪些信息？如何协调手机使用与对周围环境的注意？
- RQ2：参与者何时报告感到 overwhelmed 或获得支持？当时伴随哪些信息和情境条件？他们如何描述这些体验对出行的影响？
- RQ3：如何依据这些发现建立信息分类，并提出有关信息时机、详细程度和传达方式的设计建议？

## 四、数据收集方法

### 研究取向与分析单位

本研究采用质性实地研究，结合步行观察、自愿的简短即时口述、关键导航片段录像，以及事后半结构式访谈。行为、环境和参与者解释将相互对照。事件次数仅辅助描述，不用于直接测量神经层面的注意力、生理疲劳，或证明导航对出行愉悦感的因果影响。

分析单位为“信息交互片段”：触发因素、相关信息、行动、参与者体验与结果组成的一段过程。

我们明确区分“参与者报告应付不过来”和“研究者怀疑出现困难”。参与者可以在当下表达，也可以在事后回看时确认；停顿、反复查看或走错路本身不能证明 overwhelmed。其他状态同样需要记录，包括可应对的费力、不确定但不困扰、得到确认，以及顺利前进。心理费力与身体疲惫分别记录。

| 研究问题 | 所需证据 | 收集与分析方式 |
|---|---|---|
| RQ1 | 信息需求、可见行为与旅程阶段 | 简短背景访谈、步行观察、事件时间线 |
| RQ2 | 主观体验、情境触发因素及出行影响 | 自愿口述、关键片段录像与事后访谈，区分报告和研究者推测 |
| RQ3 | 信息作用、情境要求及有帮助的支持 | 跨案例矩阵，连接体验、行为证据与设计建议 |

### 准备与预研究

正式收集前准备研究流程、说明书、知情同意书、路线与拍摄计划，并取得所需伦理批准。研究者考察一条约15—20分钟的公共步行路线，由交通设施出口通向公共目的地入口。仅在熟悉程度、可达性或安全等原因使主路线不合适时使用备用路线，并记录差异。

获批后邀请一名符合条件的志愿者开展预研究，不计入正式样本。预研究重点检查：任务时长、摄像操作、时间标记、回看片段的查找效率，以及口述和摄像是否明显干扰行走。

### 每名参与者集中完成一次活动

单次约45—60分钟，不要求再次到场。

| 环节 | 时间 |
|---|---:|
| 知情同意与简短背景访谈 | 5—10分钟 |
| 步行观察与关键片段记录 | 15—20分钟 |
| 事后访谈及选段回看 | 25—30分钟 |

参与者使用自己平常的导航应用和设置，按自己的节奏行走，不设置速度目标。一位研究者陪同、标记事件并关注路线情况，另一位负责摄像。

### 标记 overwhelmed 的时刻

出发前向参与者说明：如果某个时刻觉得难以应付，或某条信息特别有帮助，可以说一句“标记一下”，再根据意愿简短说明正在想什么；也可以保持沉默，留到之后讨论。

采用自愿、片段式的即时口述，不要求持续 think aloud。研究者不反复提醒“你是否 overwhelmed”，也不在过马路时追问。研究者主动提问、协助或其他中断会被记录，以便判断研究过程本身的影响。

观察笔记区分：

- 参与者当下明确表达的体验；
- 研究者观察到的行为，如停顿、切换地图、重新定向、求助和修正路线；
- 研究者提出、但仍待参与者确认的解释。

### 关键导航片段录像

在事先考察的决策点，经许可与单独同意后记录简短片段。参与者标记或出现疑似困难时，也可以启动录像。

画面以相关情境和行动为主，包括路牌、分岔路、入口、周围行人或交通条件，以及参与者同意记录的手部和设备操作。不以面部表情判定心理状态。

每段录像与事件笔记共用时间标记，记录：

| 记录项 | 内容 |
|---|---|
| 事件前后 | 刚才发生了什么，随后如何行动 |
| 信息需求 | 参与者正在寻找或确认什么 |
| 信息与环境 | 提示内容、路牌、路径、入口及周围状况 |
| 即时表达 | 参与者当时说的话；未口述则标明 |
| 结果 | 得到确认、继续前进、求助、绕路或仍未解决 |
| 记录缺口 | 是否未拍到起点、画面遮挡或信息无法确认 |

同时保留少量顺利或获得帮助的片段，以免仅记录困难、预先强化负面结论。

若录像在困难出现后才开始，不能假定已记录其触发原因；缺失的前段应明确标记，并通过访谈补充。参与者不需要为了摄像重演困扰。

### 事后访谈与视频辅助回顾

先让参与者自由描述旅程，再结合笔记和短视频回顾约三至五个片段，尽可能包含至少一个顺利或有帮助的片段。

核心提问包括：

- “你当时想弄清楚什么？”
- “那个时刻对你来说是什么感受？”
- “什么让下一步变得更容易或更困难？”
- “这次行程有没有影响你欣赏周围环境、继续活动或探索的心情？”

参与者可以确认、否定或修改研究者解释。“没有影响”和正面体验都作为有效结果保留。

在同一访谈中，请参与者补充一次自己选择的近期真实出行，以了解是否有过改变计划、继续探索或放弃目的地的经历。回忆经历、当下表达的意愿与现场实际行为将分开记录，不把“可能不想再走”当作已经发生的退出行为。

分析同时考虑天气、步行体力、赶时间、原有疲惫和情绪等解释，避免把所有不愉快都归因于导航。

为控制时间，视频回顾替代原来的信息卡片活动。若参与者不愿录像或录音，可以采用笔记完成观察与访谈，并记录材料形式的差异。

研究者记录参与者是独立抵达、获得帮助后抵达，还是没有抵达，并说明活动结束原因。研究时限或主动退出不自动等同于导航失败。若无法在预计时间内完成路线，在安全地点结束并保留简短访谈，不要求参与者坚持完成。

### 分析与综合

采用跨案例质性矩阵，保留原始笔记、录像和访谈的对应关系。访谈录音转写并核查；视频先建立事件索引，再对选定片段和相关话语详细整理，不逐帧分析全部影像。

两位研究者分别解释前两个案例，讨论差异，形成共享编码结构，再整理其余材料。保留修改记录和未解决分歧。

矩阵记录参与者、旅程阶段、所需信息、呈现与环境条件、行为、即时话语、事后解释、overwhelmed 的报告状态、应对及结果。明确区分当下报告、事后回忆、可见行为和研究者推测。

“定向、引导、确认、恢复”等只是可修改的初步信息作用分类。重点检查反例，例如同样反复看手机却没有感到负担，或主观感到 overwhelmed 却没有明显停顿。同一人的多个片段不当作多个独立样本。

设计建议遵循：观察片段 → 参与者解释 → 情境分析 → 建议的信息支持。每条建议包括支持案例、反例或适用边界，以及是否经过评价。团队内部用两个去标识化案例检查证据可追溯性，不将其视为框架有效性的用户测试。

## 五、参与者与招募

计划6名核心参与者，确有证据缺口且时间允许时最多补充2名，另有1名独立预研究参与者。参与者为过去六个月内迁居香港、使用手机导航、不熟悉所选路线且能够舒适完成步行的成年人。支持英语或普通话。

“六个月”是招募操作标准，不是导航能力分界线；路线熟悉程度、工具经验和语言熟悉程度单独记录。

通过允许发布邀请的大学和初到香港人群网络进行目的性便利招募，并接受自愿转介。不设置分组配额，也不比较本地人与初来者。六例是课程项目的务实目标，不保证饱和或代表性；完成后检查缺失视角再决定是否补充。证据不足时缩小结论范围。

有兴趣者私下联系团队，简短筛选资格。避免参与压力，说明参与与否不影响成绩或服务。当前不安排报酬。报告承认样本可能偏向学生。

## 六、参与者说明与知情同意

预约前及活动当天提供中英文说明，解释目的、路线、时长、自愿口述、音视频记录选项、数据处理、退出方式和联系人。正式活动及预研究均在所需伦理批准后开展，收集前取得书面或电子同意。

录像、录音、去标识化引文与可识别影像的展示分别取得许可；同意研究记录不等于同意公开播放。拒绝拍摄不影响采用笔记形式参与。

参与者可拒答、暂停摄像或活动、随时退出。建议在活动后七天内允许申请删除可识别数据，之后才按获批方案进行不可逆匿名化。天气、拥挤或不适时暂停、调整或改期。招募前确认学生与导师联系方式。

## 七、保密与数据管理

采用P01等编号，同意和联系资料与媒体、转写及矩阵分开，保存在学校认可、限制访问的空间。

摄像尽量避免面孔、私人屏幕、消息和支付细节，并遵守场所拍摄规定。偶然入镜的旁观者或私人信息不作为分析对象，在保留的片段中删除或遮蔽。原始街景录像不称为匿名数据，报告使用去标识化描述或处理后的静帧，不展示可识别的原始录像。

音视频按参与者编号和时间索引，用于回忆及分析。存储位置、保留期限与删除安排在招募前与导师确认。不需要的可识别片段依获批计划及时移除。原始媒体不上传公共AI服务或个人自动云备份；如采用转写工具，应获准并提前说明。

## 八、预期数据类型

- 参与者背景、路线熟悉程度及导航习惯；
- 带时间标记的观察笔记与旅程时间线；
- 经同意的关键片段录像、视频索引与即时口述；
- 访谈录音或笔记、核查后的转写；
- 事件次数和大致时长、跨案例矩阵及分析备忘录；
- 信息分类、设计建议及说明适用边界的案例。

## 十、预期成果与局限

研究将描述信息与情境要求如何关联参与者报告的 overwhelmed、安心或可应对的费力体验，形成情境化的信息分类与初步设计框架。案例亦将展示参与者如何理解这些时刻对出行愉悦感、信心和继续探索意愿的影响。

框架连接信息作用、时机、详细程度、传达方式与确认或恢复支持。其完整性、可用性和减轻负担的效果仍需后续评价。

小规模便利样本、指定路线、摄像及研究者在场、自愿口述、事后回忆和不同导航应用都会限制解释。一次短途步行和访谈不能证明长期减少城市探索，或证实导航导致疲劳与愉悦感下降。本研究不单独识别初来者身份的影响，不推断神经过程，也不直接推广到驾驶、骑行或所有初到香港的人群。
