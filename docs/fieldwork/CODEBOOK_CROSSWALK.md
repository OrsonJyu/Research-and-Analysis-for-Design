# 行为代码对照 Action-code crosswalk

当前来源是[用户提供的 v3 手册](MANUAL_CN.md)和[记录表](RECORD_FORM_CN.md)，以及 2026-10-29 用户对新增代码的决定（[D015](../DECISIONS.md)）。旧标签来自[10 月汇报](../../deliverables/presentations/presentation-02/SLIDE_TEXT.md)。下表用于跨版本理解，未声称已完成编码一致性检验。

| 当前简写 | 旧标签 | 可见行为与边界 |
|---|---|---|
| S | STOP | 看见停步；起止不清注明；红灯、休息等原因不由代码决定 |
| P | PHONE_VIEW | 能辨认看屏幕；只拿着手机不算 |
| I | PHONE_INPUT | 看见点、滑或输入；目的未知不猜 |
| H | HEAD_TURN | 可见头部方向变化；不自动等于看路牌 |
| G | SIGN_VIEW | 能辨认正在看的具体标识；不确定则注明 |
| Q | HELP_REQUEST | 听清或可靠记录向他人求助 |
| R | R_PROMPT | 研究员提醒／帮助；记时间、内容、原因 |
| T | RESEARCHER_TALK | 2026-10-29 新增（D015）。参与者与研究员交谈，发起或回应都算；内容不明标 T?。研究员一方的说明、提示和帮助仍记 R |
| K | KIOSK_USE | 2026-10-29 新增（D015）。可见查看或触摸公共电子导览屏，查看与输入在描述里区分；不记作手机 I；他人使用不算 K；静态目录板记 G |

### T／K 的来源与回查

T 和 K 最早是 P04（Tom）编码时加的工作代码，P01、P02、P05 的筛选版编码沿用。P03（Peter）的英文编码用 G\*（看电子导览屏）和 D\*（在导览屏上输入），现统一并入 K：G\* → K（查看），D\* → K（输入）。

待回查：
- P03 编码中的 G\*／D\* 记录（V24、V47–V55 一带）改写为 K。
- P04 V29 的「K+I」写法与「不记作手机 I」冲突，改为 K 并在描述中写明输入。
- 向研究员提问时是否同时记 Q（P04 V22 写作 T/Q→R），由团队约定。

可以同时出现多个行为，但起止不同则分行。时间用香港时钟；不确定写“约”，事后补记标明，漏看时段如实保留。行为原因及体验在访谈和解释栏分开记录。

**PHONE_SEARCH** 是早期讨论中的可新增例子，当前简写表没有为其规定独立符号。若实际资料需要新增代码，应记录定义、证据要求、版本及对先前资料的回查，不静默改变旧标签。
