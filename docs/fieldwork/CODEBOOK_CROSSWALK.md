# 行为代码对照 Action-code crosswalk

当前来源是[用户提供的 v3 手册](MANUAL_CN.md)和[记录表](RECORD_FORM_CN.md)。旧标签来自[10 月汇报](../../deliverables/presentations/presentation-02/SLIDE_TEXT.md)。下表用于跨版本理解，未声称已完成编码一致性检验。

| 当前简写 | 旧标签 | 可见行为与边界 |
|---|---|---|
| S | STOP | 看见停步；起止不清注明；红灯、休息等原因不由代码决定 |
| P | PHONE_VIEW | 能辨认看屏幕；只拿着手机不算 |
| I | PHONE_INPUT | 看见点、滑或输入；目的未知不猜 |
| H | HEAD_TURN | 可见头部方向变化；不自动等于看路牌 |
| G | SIGN_VIEW | 能辨认正在看的具体标识；不确定则注明 |
| Q | HELP_REQUEST | 听清或可靠记录向他人求助 |
| R | R_PROMPT | 研究员提醒／帮助；记时间、内容、原因 |

可以同时出现多个行为，但起止不同则分行。时间用香港时钟；不确定写“约”，事后补记标明，漏看时段如实保留。行为原因及体验在访谈和解释栏分开记录。

**PHONE_SEARCH** 是早期讨论中的可新增例子，当前简写表没有为其规定独立符号。若实际资料需要新增代码，应记录定义、证据要求、版本及对先前资料的回查，不静默改变旧标签。

手机输入不直接证明正在搜索，GPS 低速不直接证明 STOP，停步／看手机不直接证明 overwhelmed。视频用于核对笔记及片段回顾，不另建独立视频编码数据集。
