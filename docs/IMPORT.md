# 首次导入与完整性 Import integrity

大型原件在传输时可能临时分成多个数据片段。`.github/imports/manifest.json` 若存在，表示仍有待还原文件；`scripts/restore_import.py` 只接受最终文件目录中登记的路径、字节数与 SHA-256，并对每一片段和完整原件分别核对。

临时片段完成还原后删除。正式交付仍是原始文件名下的完整 PDF、ZIP 或书籍文件，不以片段替代日常阅读入口。当前执行手册和表格均作为完整原件保存。

此流程属于本次资料导入，不表示日后的后台定时同步。只有远端文件树与最终本地目录一致，才可以宣布本次同步完成。
