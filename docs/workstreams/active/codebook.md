# 证据充分性与 qualitative codebook

## 顺序
1. 补完访谈后，把观察与参与者自述对齐。
2. 检查证据是否足以回答研究问题：关键事件是否有足够情境和解释。
3. 足够：建立 qualitative codebook，做个案内和跨案例分析；不足：再招一位参与者并重复流程。

## 输入
- 五条候选模式（Pre-1028 第 13 页）：途经点交接、地下过街、看得见楼找不到入口、室内换信息源、手机放低与路口查看。
- [跨案例笔记](../../fieldwork/CROSS_CASE_NOTES.md) T1–T8；事件记录格式＝情境＋信息来源＋行为序列＋参与者自述。

- [ ] 到达途经点的统一判定规则。
- [ ] 跨案例比较单位是否采用"决策片段"。
